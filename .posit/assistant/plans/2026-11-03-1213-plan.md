# Plan: trivia() jugable en el navegador con webR

Requisito previo (en curso, lo hace el usuario): `territorial` publicado en
r-universe (`https://bastianolea.r-universe.dev`) con binario WebAssembly.

## 1. Verificar el binario wasm

- Confirmar que el paquete aparece en `https://bastianolea.r-universe.dev/api/packages/territorial`.
- Confirmar el binario: `https://bastianolea.r-universe.dev/bin/emscripten/contrib/<version R>/PACKAGES`
  contiene `Package: territorial`.
- Probar en el REPL oficial (https://webr.r-wasm.org/latest/):
  ```r
  install.packages("territorial",
    repos = c("https://bastianolea.r-universe.dev", "https://repo.r-wasm.org"))
  library(territorial)
  trivia()
  ```
  Comprobar que `menu()` acepta respuestas, que `Sys.sleep()` no da problemas
  y que los emojis y el formato de cli se ven bien.

## 2. Opción rápida: link compartible al REPL oficial

- Generar un link con el código anterior precargado, ya sea con el botón
  "Share" del editor de webR o con el paquete `livelink`.
- Agregar el link al README (`README.qmd`, y luego renderizar) y a la
  documentación de `trivia()` (`R/trivia.R`, sección `@details` o `@seealso`).

## 3. Página propia: solo consola y la trivia parte sola

Se publica dentro del sitio pkgdown (GitHub Pages, https://bastianolea.github.io/territorial/).

- Crear `pkgdown/assets/trivia/index.html` (pkgdown copia `pkgdown/assets/` a la
  raíz del sitio, así que quedaría en `.../territorial/trivia/`):
  - Importar `Console` desde `https://webr.r-wasm.org/latest/webr.mjs`.
  - Salida en un `<pre>` y un `<input>` que envíe cada línea con `con.stdin()` al presionar Enter.
  - Al cargar, ejecutar `options(cli.num_colors = 1)`, luego `install.packages(...)`
    (con los repos de r-universe y r-wasm), `library(territorial)` y `trivia()`.
  - Mostrar un mensaje de "Cargando R..." y estilo acorde al sitio (colores de `_pkgdown.yml`).
  - Opcional: un botón "Jugar de nuevo" que envíe `trivia()`.
- Cross-origin isolation: `menu()` necesita el canal SharedArrayBuffer, y
  GitHub Pages no envía los headers COOP/COEP.
  - Agregar `pkgdown/assets/trivia/coi-serviceworker.js` (de
    https://github.com/gzuidhof/coi-serviceworker; leer el script antes de incluirlo)
    y cargarlo en `index.html` antes del módulo de webR.
  - Alternativa si falla: publicar en Netlify o Cloudflare Pages con un archivo `_headers`.
- Agregar un enlace "Jugar trivia" en el navbar de `_pkgdown.yml`.
- Probar localmente con un servidor que envíe los headers (por ejemplo `httpuv`
  o `servr`), y después en GitHub Pages, tras correr el workflow `pkgdown.yaml`.

## 4. (Opcional) webrarian

Úsalo si se quiere una IDE en vez de solo una consola:
`catalog()`, `acquire_package("territorial")`, `bind()`, `reading_room()`.
Antes, revisar `check_inventory()` y que funcione `menu()`. Es mejor publicarlo
en Netlify o Cloudflare por los headers.

## Fuera de alcance

quarto-live o quarto-webr: sus celdas no son interactivas y `menu()` falla.
Shinylive: requeriría reescribir la trivia.
