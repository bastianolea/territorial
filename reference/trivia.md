# Jugar a una trivia de comunas y regiones de Chile

Inicia una trivia interactiva en la consola para probar tu conocimientos
sobre los territorios de Chile! Aparecerán 7 preguntas en la consola,
una por una, y debes responder con el número de la alternativa
correspondiente. Al final aparecerá tu puntaje! Son 5 tipos de preguntas
distintas, y los territorios que aparecen son aleatorios, mientras que
las alternativas están diseñadas para confundirte!

## Uso

``` r
trivia()
```

## Detalles

Las preguntas son: ¿En qué región está la comuna? ¿En qué región está
las comuna? ¿Cuál de estas comunas es urbana/rural? ¿En qué provincia
está la comuna?

También puedes [jugar la trivia en tu
navegador](https://bastianolea.github.io/territorial/articles/trivia.html),
sin instalar R.

## Ejemplos

``` r
if (FALSE) { # interactive()
trivia()
}
```
